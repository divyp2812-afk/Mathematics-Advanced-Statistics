# PR-3: Statistical Distribution Analysis and Hypothesis Testing

## 📌 Project Overview

This project demonstrates the application of **Probability Distributions** and **Statistical Hypothesis Testing** using Python. It is divided into two parts:

The project helps understand how different probability distributions fit real-world data and how statistical tests are used for decision-making.
