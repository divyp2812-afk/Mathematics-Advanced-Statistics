# Probability & Statistics Mini Project (PR-1)

## Project Overview
This notebook demonstrates core probability concepts using a student performance dataset (`study_hours.csv`). The project combines theory and practical analysis to show how probability can be used to understand factors that influence exam success.

## Topics Covered

### 1. Understanding the Basics
- Definition of probability
- Experiment, sample space, and events
- Real-world examples using coins, dice, and student outcomes

### 2. Types of Events
- Introduction to different event categories in probability

### 3. Random Variables & Distributions
- Empirical probability calculation from dataset
- Theoretical probability comparison
- Binomial distribution for student pass outcomes
- Mean and variance calculations

### 4. Venn Diagram Analysis
- Relationship between:
  - Students studying more than 10 hours/week
  - Students with attendance above 80%
- Visualized using a Venn diagram

### 5. Contingency Tables & Probability Calculations
- Joint Probability
- Marginal Probability
- Conditional Probability
- Analysis of group discussion participation and exam results

### 6. Understanding Relationships
- Explanation of conditional probability
- Example: Probability of passing given high attendance

### 7. Bayes' Theorem Application
- Demonstrates how prior and conditional probabilities can be used to estimate outcomes
- Calculates posterior probability using Bayes' Theorem

### Final Summary
The notebook concludes with key findings:
- Higher study hours increase pass probability.
- Better attendance improves exam performance.
- Participation in group discussions positively influences success.
