# PR-2: Statistical Analysis and Hypothesis Testing

## Overview
This project demonstrates the application of inferential statistics and statistical hypothesis testing using Python. The notebook is divided into two parts:

- **Part A:** Theoretical concepts of inferential statistics and hypothesis testing.
- **Part B:** Practical implementation of statistical tests on a healthcare dataset.

## Files Included

- `PR-2_PART-A.ipynb` – Theory and explanations of statistical concepts.
- `PR-2_PART-B.ipynb` – Python implementation of statistical analysis.
- `health_dataset.csv` – Dataset used for analysis.

- Role in decision making

# Part B – Data Analysis and Testing

### Dataset Analysis

The healthcare dataset is analyzed using various inferential statistical techniques.

### Statistical Tasks Performed

#### 1. Hypothesis Formulation
- Defined Null and Alternative Hypotheses for different scenarios.

#### 2. Confidence Interval Calculation
- Calculated 95% confidence intervals for selected variables.

#### 3. Critical Value and P-Value Analysis
- Computed test statistics.
- Compared p-values with significance levels.

#### 4. Independent T-Test
- Compared means between two groups.

#### 5. Chi-Square Test
- Tested association between categorical variables.

#### 6. ANOVA Test
- Compared means among multiple groups.

#### 7. Correlation and Covariance
- Measured relationships between numerical variables.

#### 8. Interpretation of Results
- Accepted or rejected hypotheses based on statistical evidence.

## Conclusion

This project provides both theoretical knowledge and practical experience in inferential statistics and hypothesis testing. It demonstrates how statistical techniques can be applied to real-world healthcare data for analysis and decision-making.
